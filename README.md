# Banco de TV

Asistente de diagnóstico y registro de reparaciones de TV LED.
App web instalable en Android: https://nmanzaneda.github.io

- `index.html` — la app completa (diagnóstico, casos, valores de referencia)
- `sw.js` — funcionamiento sin internet
- `.well-known/assetlinks.json` — se agrega después de generar el APK en PWABuilder
